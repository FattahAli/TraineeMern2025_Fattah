
## MongoDB Shell Commands (`mongosh`)

### Basic Commands
```bash
show dbs               # List all databases
use dbName             # Switch to (or create) a database
show collections       # List collections in current DB
```

### Create & Drop Collection
```js
db.createCollection("people")
db.people.drop()
```

### CRUD Operations
```js
db.people.find()                     // Find all documents
db.people.find().limit(5)           // Limit results to 5
db.people.insertOne({ name: "Ali" }) // Insert one document

db.people.updateOne(
  { name: "Ali" },
  { $set: { age: 25 } }
)

db.people.updateMany(
  { country: "USA" },
  { $set: { verified: true } }
)

db.people.deleteOne({ name: "Ali" })
db.people.deleteMany({ country: "USA" })
```

##  Schema Validation
```js
db.createCollection("hosts", {
  validator: {
    $jsonSchema: {
      bsonType: "object",
      required: ["email"],
      properties: {
        email: {
          bsonType: "string",
          pattern: "@mongodb.com$"
        },
        phone: {
          bsonType: "string",
          description: "must be a string"
        }
      }
    }
  }
})
```

## Aggregation Example
```js
db.listings.aggregate([
  {
    $match: {
      number_of_reviews: { $gte: 100 }
    }
  },
  {
    $group: {
      _id: "$property_type",
      count: { $sum: 1 },
      reviewCount: { $sum: "$number_of_reviews" }
    }
  }
])
```

##  Atomic Update Operators
- `$set` – Set a field value
- `$unset` – Remove a field
