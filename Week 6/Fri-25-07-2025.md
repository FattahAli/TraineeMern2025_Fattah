

# Node Cron & Express.js

## Node Cron

**Node Cron** is a task scheduler for JavaScript. It allows you to schedule tasks to run at specific intervals using a simple cron syntax.

### Example:
```js
const cron = require("node-cron");

cron.schedule("* * * * *", () => {
  console.log("Running a task every minute");
});
```

- `* * * * *` → Runs every minute
- Cron jobs are ideal for scheduled backups, emails, cleanups, and automation.

---

## Node.js vs Express.js

- **Node.js** is the core runtime environment to run JavaScript on the server side.
- **Express.js** is a framework built on top of Node.js to simplify server creation, routing, and middleware handling.

### Analogy:
- **Node.js** is like a raw engine.
- **Express.js** is the user-friendly interface and controls over that engine.

---

## What is Express.js?

- Express.js is a **web framework** for Node.js.
- Provides features like:
  - Routing
  - Middleware
  - Template engine support (e.g., EJS)
  - Simplified request/response handling

---

## Why Express.js?

- Using core HTTP module in Node.js can be verbose and complex.
- Express simplifies:
  - Defining routes
  - Handling requests/responses
  - Managing views

---

## Routing in Express

**Routing** is the process of defining endpoints (URLs) that your server responds to.

Example routes:
```
/home
/about
/profile
/profile/:username/:id
```

## Express with EJS Templating Example

### Server (app.js)
```js
const express = require("express");
const app = express();

// Setting view engine
app.set("view engine", "ejs");

// Routing
app.get("/", (req, res) => {
  res.render("index");
});

app.listen(3000, () => console.log("server started on 3000"));
```

---

### View (views/index.ejs)
```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8" />
  <meta name="viewport" content="width=device-width, initial-scale=1.0"/>
  <title>Document</title>
</head>
<body>
  <h1>Hey</h1>
</body>
</html>
```

- This setup uses **EJS** (Embedded JavaScript Templates) to render HTML pages from the server.
- EJS lets you dynamically inject data into HTML views.
