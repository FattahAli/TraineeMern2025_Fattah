# Relational vs Non-Relational Databases

## Relational Databases
- **Structured**: Data is organized in rows and columns (tables).
- **Tables**: Data is stored in tables.
- **Primary Key**: Each table has a unique identifier (primary key).
- **Foreign Key**: When a key from one table appears in another, it becomes a foreign key.

###  Features
- **Consistency**
- **Security**
- **Ease of Backup & Recovery**

---

## Non-Relational Databases
### Types:
- **Key-Value Stores**
- **Column Stores**
- **Graph Databases**
- **Document Stores**

### Features
- **Flexibility**
- **Scalability**
- **Cost-Effectiveness**

---

# MongoDB Overview

## Structure
- A **collection** is a list of **documents**.
- Supports **horizontal scaling**.
- Uses a **leader (primary)** and **secondaries**.
  - **Writes** go to the **leader**.
  - **Reads** can happen from **secondaries**.
